# Privacy

Observatory has no account, backend, cloud synchronization, telemetry, advertising, or error-reporting service. Projects, preferences, images, and trash are stored in the browser’s IndexedDB. Export is initiated by the user and produces a local download.

Ordinary use makes no application network requests. External Story Shack links open only when chosen.

WebMCP is an explicit browser-agent collaboration surface. When a user asks an agent to invoke a read tool, the bounded content returned by that tool is disclosed to that chosen agent. Mutation tools validate and save locally; recoverable deletion requires visible human approval. No permanent purge tool exists.
